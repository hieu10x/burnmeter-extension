Cursor Teams or Enterprise admin

Create an Admin API key at cursor.com/dashboard → Settings → Admin API keys, then run:

curl -s -u KEY: https://api.cursor.com/teams/members > cursor-members.json
curl -s -u KEY: -X POST https://api.cursor.com/teams/spend \
  -H 'Content-Type: application/json' -d '{"pageSize":500}' > cursor-spend.json

Delete the key afterwards if you like. If cursor-spend.json says "totalPages": 2 or more, repeat with "page":2 and add that file too.

GitHub Copilot org owner or billing manager

Usage report: Organization settings → Billing and licensing → Usage → download the Copilot usage report (CSV).

Seats, to find seats nobody uses (needs the gh CLI):

gh api /orgs/YOUR-ORG/copilot/billing/seats \
  --paginate --slurp > copilot-seats.json

Claude Team or Enterprise owner

claude.ai → your initials → Analytics → spend report → pick the last 30 days → Export CSV.

Covers Chat, Claude Code and the other Claude products, per person and model.

Claude Code / Codex on API keys

Each developer runs this and sends you the file (no prompts, code or paths in it):

npx burnmeter --export me.json --as their@company.com
